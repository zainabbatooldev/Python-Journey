# Phase 01: Python Basics Notes

## What is Python?

Python is a high-level, interpreted, and beginner-friendly programming language. It is widely used in web development, automation, artificial intelligence, data science, cybersecurity, and software development.

---

# 1. Comments

Comments make code easier to understand.

### Single-line Comment

```python
# This is a comment
```

---

# 2. Print Statement

The `print()` function displays output on the screen.

```python
print("Hello, World!")
```

---

# 3. Variables

Variables store data.

```python
name = "Zainab"
age = 20
```

---

# 4. f-Strings

Used to format output.

```python
name = "Ali"
print(f"Hello {name}")
```

---

# 5. Data Types

| Data Type | Example |
|-----------|---------|
| int | 10 |
| float | 10.5 |
| str | "Python" |
| bool | True |

---

# 6. Input and Output

Take input from the user.

```python
name = input("Enter your name: ")
print(name)
```

---

# 7. type() Function

Returns the data type of a variable.

```python
age = 20
print(type(age))
```

---

# 8. Type Casting

Converts one data type into another.

```python
age = int(input("Enter age: "))
price = float(input("Enter price: "))
```
