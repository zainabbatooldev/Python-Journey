# Phase 01: Python Basics

## 📌 Overview
This phase introduces the fundamentals of Python programming. It covers Python syntax, variables, data types, user input, operators, and basic programming concepts through topic-wise learning and practice.

## 📚 Topics Covered
- Comments
- Print Statement
- Variables
- f-Strings
- Data Types
- Input and Output
- type() Function
- Type Casting
- Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Escape Sequences

## 💻 Practice Programs
- Print Poem
- Student Profile
- Add Two Numbers

## 🎯 Learning Outcomes
After completing this phase, I can:
- Write basic Python programs.
- Use variables and data types.
- Take user input.
- Perform arithmetic operations.
- Use f-strings for formatted output.
- Apply type casting.
- Understand comparison and assignment operators.
- Write clean and readable Python code.
